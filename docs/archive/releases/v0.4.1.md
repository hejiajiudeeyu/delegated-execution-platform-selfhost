# Release `v0.4.1`

## Release

- version: `v0.4.1`
- date: `2026-08-02`

## Summary

Patch on top of `v0.4.0`. One fix, and it matters more than its size suggests.

- **the stuck-call guardrail now fires.** `isStuckCall` — the check behind the
  attention feed's "calls past the grace window with no terminal event" — read
  `latest.recorded_at`, but request events are stamped with `at` and nothing in
  the production path has ever written `recorded_at`. The lookup was always
  `undefined`, so the function always returned `false`. Every real call was
  invisible to the one guardrail meant to stop a call becoming a silent
  permanent pending (NFR-R01).

  It passed its own test because the test hand-set `recorded_at` on the event.
  Both the check and that fixture are corrected; the fixture now ages the field
  production actually writes, and it fails against the old code.

  Anyone running `v0.4.0` or earlier should assume their attention feed has
  never reported a stuck call, and that the absence of such reports was not
  evidence of their absence.

## Compatibility

Drop-in over `v0.4.0`. No environment or API changes.
