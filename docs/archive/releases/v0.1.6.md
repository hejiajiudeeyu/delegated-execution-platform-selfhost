# Release `v0.1.6`

## Release

- version: `v0.1.6`
- date: `2026-07-04`

## Summary

- console lost-passphrase recovery: bootstrap-secret guarded `POST /session/recover` on the gateway plus a browser recovery flow (type `RESET`) — closes the T-503 SSH-reset violation path
- state-driven console session panel (setup / locked / unlocked / unreachable) with admin-credential next-step guidance, network-failure and loading states, and a gateway health card on the overview
- review lifecycle and billing explainability (tenant_id = user_id) surfaced in the console; review queue prioritized in navigation
- platform-api requires `@delexec/contracts@^0.1.3` (published), fixing the source-built public-stack boot crash (`validateCatalogGuidanceFields` missing from npm 0.1.2)
- platform-api logs unhandled route and billing errors with stacks instead of returning silent 500s

## Notes

- **operator action required for recovery:** the gateway only enables `POST /session/recover` when `PLATFORM_CONSOLE_BOOTSTRAP_SECRET` is set in the gateway environment; set it before relying on the lost-passphrase flow and record it in the operations handover
- public-stack operators can roll **gateway only** to `rsp-gateway:v0.1.6` for the recovery + session UI work; rolling `rsp-platform` to `v0.1.6` additionally picks up the contracts repin and 500 diagnostics
- recovery is destructive by design: it replaces the secret store, clears sessions, and requires the admin key to be re-entered afterwards
