# Release `v0.1.7`

## Release

- version: `v0.1.7`
- date: `2026-07-04`

## Summary

- console gateway-API base fix: behind subpath edges (`/console/` + `/gateway/`), session and proxy calls previously escaped the `/gateway` prefix (leading-slash `new URL` join) and the console showed "Gateway Unreachable" even though static assets loaded — the served console UI had never actually worked through an edge proxy
- URL joining now goes through `gateway-url.js` helpers (normalized trailing-slash base, stripped leading slashes), unit-tested for direct-origin, subpath, and query-string cases
