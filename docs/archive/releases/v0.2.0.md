# Release `v0.2.0`

## Release

- version: `v0.2.0`
- date: `2026-07-04`

## Summary

- **operator console rebuilt** (owner decision after the 2026-07-04 manual walkthrough surfaced ten interaction defects, M1–M10): React SPA on the family stack replaces the string-template vanilla console; gateway API unchanged
- interaction rules now enforced by construction: inline feedback beside every action, non-2xx never renders as an empty state, credential save probes the platform and only then reports "verified", destructive/funding actions have no defaults and require explicit confirmation, recovery is a three-step wizard with a blank confirmation field
- zh-first copy; unified session states (未初始化/已锁定/已解锁/网关不可达); responsive layout (mobile drawer nav, centered max-width on wide screens)
- console assets are now content-fingerprinted (Vite build); the gateway serves `index.html` with `no-cache` and `/assets/*` as immutable — stale-JS-after-release (M1) is structurally gone
- retired: the legacy vanilla console modules and the never-served React prototype pages
- `Dockerfile.workspace` gains a `console-build` stage; a missing `.dockerignore` was added (host `node_modules` no longer leaks into image builds)

## Validation

- platform unit 31 passed (gateway-url + API classification contract tests) and integration 15 passed / 2 skipped, including new static-serving assertions (fingerprinted bundle, cache headers)

- `test:public-stack-smoke` in source-build mode exercises the new `console-build` Docker stage end to end
